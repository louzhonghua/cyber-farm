# 霓虹农场 MVP

一个基于 React + Vite 的可运行原型，覆盖了赛博农场的首个可玩闭环：

- 5 位具有职业、性格、状态和个人记忆的居民
- 作物收获、放牧、饲料、仓库整理等结构化任务
- 任务状态流转（等待、执行、完成）与基础资源状态变化
- 可识别收获、放牧与情感交流的对话入口
- 本地持久化记忆与任务数据（浏览器 `localStorage`）

## 启动

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 当前边界

这是前端可验证原型：对话规则由 `src/App.jsx` 中的本地意图匹配模拟，尚未接入大语言模型或服务端数据库。

生产版本建议把：

1. 居民、世界和任务状态迁到后端数据库；
2. 对话解析及角色台词替换为模型 API；
3. 通过受限工具调用，让模型只能创建任务、查询世界、写入候选记忆；
4. 使用向量检索召回与当前对话相关的长期记忆。
